# Proyecto 2 - Comunicación Asertiva  
## Negociación Técnica en Equipos de Desarrollo de Software

---

## Descripción del Proyecto

Este proyecto consiste en la simulación de un entorno real de desarrollo de software, en el cual se aplican técnicas de comunicación asertiva, toma de requerimientos y negociación técnica para proponer una solución a problemas identificados en un negocio real.

Para ello, se realizaron entrevistas a dos negocios:

- Farmacia del Ángel  
- Abarrotería Gandhi  

Posteriormente, se analizó la información obtenida y se desarrolló una propuesta tecnológica enfocada en mejorar la eficiencia del negocio, la atención al cliente y el control de procesos internos.

---

## Objetivo del Proyecto

Desarrollar una solución tecnológica basada en problemas reales, aplicando:

- Comunicación asertiva  
- Trabajo en equipo  
- Negociación técnica  
- Documentación profesional  
- Uso de herramientas colaborativas  

---

## Problema Principal

El proyecto se centra en la **Farmacia del Ángel**, donde se identificaron problemas como:

- Registros manuales de ventas  
- Falta de control de inventario  
- Falta de conocimiento sobre medicamentos  
- Errores en la atención  
- Falta de digitalización  
- Limitaciones de tiempo y presupuesto  

---

## Solución Propuesta

Se propone un sistema digital modular tipo servicio (SaaS), que incluye:

- Gestión de inventario  
- Punto de venta (POS)  
- Registro de clientes  
- Apoyo informativo sobre medicamentos  
- Control de productos y vencimientos  
- Interfaz sencilla y accesible  

El sistema permite adaptarse al presupuesto del cliente mediante módulos progresivos.
